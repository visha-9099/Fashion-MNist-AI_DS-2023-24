📌 Project Overview
This project focuses on building a deep learning model to classify images from the Fashion MNIST dataset. 
The dataset consists of 70,000 grayscale images of 10 different fashion categories, such as T-shirts, sneakers, and bags.
It serves as a more complex alternative to the traditional MNIST digit dataset.

🚀 Key Features
Data Preprocessing: Normalization and reshaping for better model performance.

Model Architecture: Implemented using CNNs (Convolutional Neural Networks) for high accuracy.

Training & Evaluation: Used TensorFlow/Keras to train models and evaluate their performance.

Visualization: Included data distribution plots, training loss/accuracy graphs, and confusion matrices.
